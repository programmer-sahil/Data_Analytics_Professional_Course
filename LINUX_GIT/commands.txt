popular linux commands:

1. touch (we can create files)/ echo . > 
2. mkdir (we can create folder)
3. rmdir (we can delete the folder)
4. rm  (we can delete the file)
5. cd (change directory location)
6. cd ..
7. ls (print all the items)
8. pwd (current path: print working directory)
9. clear (clean the terminal)

10. cat (cat prints the file content in the terminal.)
11. mv (renames the file. mv old.txt new.txt)
12. grep (Search for text inside a file. grep "linux" commands.txt )
13. history (Display previously executed commands)
14. whoami (Display the current username)
15. cp (Copy a file or folder. )
16. echo (to write something in a text file. echo "Hello" >  LINUX.txt)
17. head (Show the first lines of a file)
18. ls -a (print the hidden files also)
19. rm -r folder (delete non-empty folder: this is very dangerous command)
20. rm -rf .git (we can delete .git folder)
